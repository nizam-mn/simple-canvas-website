# 🖌️ Canvas App

A simple yet powerful canvas editor built using **React** and **react-konva**. Add and manipulate text and images on a canvas — perfect for designing posters, social media creatives, or just doodling around.

---

## ✨ Features

- 🖊️ **Add Text** — Write anything you want on the canvas
- 🖼️ **Add Images** — Upload and place images from your device
- 🔄 **Resize & Move Elements** — Click and drag to move, resize using handles
- 🎨 **Customize Text**:
  - Font family
  - Font size
  - Font style (bold, italic, underline)
  - Text color
  - Text alignment
- 🧭 **Element Alignment** — Align selected items to top, center, bottom, etc.
- 🔁 **Undo / Redo** — Smart history for editing
- 🧹 **Delete** — Remove any element easily
- 💾 **Download Canvas** — Export the final design as an image (PNG)
